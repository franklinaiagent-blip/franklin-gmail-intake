Franklin Gmail Intake

A private, operator-managed tool for importing authorised Gmail messages and attachments into a local evidence and document-management workspace.

What it does

Preserves original messages and attachments, records provenance, identifies duplicate files and routes relevant material to designated evidence folders or review.

Read-only Gmail access

The application requests only gmail.readonly. It does not send, delete, archive, relabel or mark messages read. Google's permission is mailbox-wide; the application selects a configured intake Inbox and a separate account's designated label.

Private use

This is not a public email service or sign-up portal. Google authorisation is managed separately for authorised accounts. This information website has no Gmail login or mailbox access.
